# NewsPulse AI — Autonomous Multi-Agent News Intelligence Platform

NewsPulse AI is an autonomous multi-agent news intelligence platform designed to discover, verify, rank, analyze, and summarize important news from multiple sources.

## 🤖 Phase 6: AI Intelligence Analysis Engine

Phase 6 builds an **AI-powered Intelligence Analysis Engine** that synthesizes structured, evidence-grounded intelligence reports for verified Event Clusters.

### 1. Evidence Grounding & Citation Strategy (`src/lib/analysis/citationBuilder.ts`)
- Every statement generated by AI is traceable to supporting original source articles (`storyId`, `articleUrl`, `publisherName`, `publishedAt`).
- Factual claims without verifiable evidence grounding are automatically omitted or flagged as uncertain.

### 2. Provider Abstraction (`src/lib/analysis/providers/`)
- `ILlmProvider` interface abstracts the underlying AI model (`GeminiProvider`, `DeterministicFallbackProvider`).
- If no external API key (`GEMINI_API_KEY`) is set in the environment, the engine seamlessly utilizes a high-quality, evidence-grounded deterministic engine without failing.

### 3. Entity Extraction & Relationship Graph (`src/lib/analysis/entityExtractor.ts`)
- Extracts structured entities categorized into `COMPANY`, `PERSON`, `ORGANIZATION`, `GOVERNMENT`, `PRODUCT`, `TECHNOLOGY`, `LOCATION`.
- Generates directed relationship triples: `Subject Entity` $\rightarrow$ `Predicate` $\rightarrow$ `Object Entity` (e.g. `OpenAI` $\rightarrow$ `released` $\rightarrow$ `ChatGPT Desktop App`).

### 4. Multi-Domain Impact & Uncertainty Detection (`src/lib/analysis/impactAssessment.ts`, `uncertaintyDetector.ts`)
- **Impact Assessment**: Evaluates implications across `TECHNOLOGY`, `BUSINESS`, `POLICY`, `RESEARCH`, `INFRASTRUCTURE`, `CONSUMERS`, `DEVELOPERS`.
- **Uncertainty Detector**: Identifies missing primary sources, conflicting reporting figures, breaking news status, and low source diversity.

> ⚠️ **AI Safety Disclaimer**:  
> AI Analysis reports are synthesized strictly from verified event evidence and primary sources. They should **NOT** be interpreted as an independent source of truth.

## 📌 API Reference

### `POST /api/analysis/[clusterId]`
Triggers generation/refresh of AI Intelligence Analysis for a specific cluster.

### `GET /api/analysis/[clusterId]`
Returns cached analysis report, citations, entities, entity relationships, uncertainties, impact assessment, and related events.

### `GET /api/events`
Returns active Event Clusters enriched with verification results, evidence graphs, and AI analysis reports.

```bash

```

```bash
# Run ESLint
```
